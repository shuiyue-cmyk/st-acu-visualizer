# 数据库可视化前端

SillyTavern 的「SP·数据库」可视化前端扩展。在聊天区渲染数据库表格，支持表格浏览、单元格编辑、整体编辑、插入行、删除行、选项面板、仪表盘等功能。

## 安装（无需手动导入 JSON）

1. 打开 SillyTavern
2. 进入 `Extensions`
3. 使用 **「Install extension from Git URL」** 入口
4. 粘贴本仓库地址：
   ```
   https://github.com/shuiyue-cmyk/st-acu-visualizer
   ```
5. 安装完成后刷新 SillyTavern

安装后扩展列表中会出现 `数据库可视化前端`。无需手动导入任何 JSON 文件。

## 环境要求

- SillyTavern `1.12.13+`（已在 `1.18.0` 上测试）
- 已安装并启用「SP·数据库」插件（本前端依赖其 `AutoCardUpdaterAPI` / `AutoCardUpdaterV2API` 公共接口）

## 功能

- 聊天区底部渲染数据库全部表格（全局数据表、主角信息表、重要角色表、主角技能表、背包物品表、任务与事件表、纪要表、选项表等）
- 表格分页浏览、搜索、倒序、多选删除
- 单元格就地编辑 / 整行编辑 / 插入新行
- 选项表 → 「行动选项」面板（点击自动填入输入框）
- 仪表盘自定义（槽位绑定表格）
- 底部按钮：打开数据库工作台（V2 新 UI）、打开表格编辑器、一键追平所选表未填楼层、全能设置、收起/展开

## 与数据库版本适配

| 前端版本 | 适配数据库 |
|---|---|
| V16.4 | 8.9 |
| V16.3 | 8.8 |
| V16.2 | 8.7.2 |
| V15.x | 7.5 ~ 8.1.x |
